# 隐私与安全

## 音频

- 音频只在本地进行 VAD/ASR；
- 插件不上传音频；
- 系统音频 helper 只把 PCM/WAV 写入本地会话目录。

## 文本

- 识别出的英文文本会发送到你在 DSH 中配置的 LLM 路由，用于翻译、术语校验；
- 不会发送到 dsh-interpret 自建服务器；
- 不包含遥测、统计上报或远程日志。

## 讲义

- 用户选择的讲义文件会复制到 ~/.dsh/interpret/reader；
- 渲染在本地进行；
- 不在插件侧联网上传；
- HTML 渲染使用无脚本、sandbox iframe。

## 本地数据

- ~/.dsh/interpret 包含历史、设置、模型、讲义；
- 删除插件不会自动删除数据；
- 卸载前请自行备份或清理。

## 安全建议

- 不要在不可信的 DSH 配置中填入未知 LLM 路由；
- 不要上传包含敏感信息的讲义到共享 profile；
- 发现安全问题请按 SECURITY.md 私下报告。
