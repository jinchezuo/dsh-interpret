# 使用指南

## 主面板

- **开始同传**：启动麦克风采集；首次会请求麦克风权限。
- **停止**：结束当前采集，等待收尾和定稿。
- **保存并刷新**：仅在会话结束后可用；把本次会话写入历史并清空字幕页。
- **讲义**：打开/收起右侧文件阅读器。
- **设置**：显示/隐藏右侧配置。

## 翻译模型

设置栏的「翻译模型」卡片会读取 DSH 当前已配置的 LLM 路由：

- **自动**：清除已保存的 provider/model，由 DSH 选择；
- **省钱优先**：优先免费/试用、Flash、Mini 等低成本档；
- **高质量**：优先 Pro、Max、Plus 等旗舰档；
- **开源系**：优先 DeepSeek、Qwen、GLM、Kimi、MiniMax 等开源家族；
- 也可以直接选择服务商和具体模型；同传进行中不可切换，停止后生效。

模型来自 DSH 已配置的路由，插件不保存 API Key；费用按 DSH 账单结算。切换后可用「翻译自测」确认实际使用的模型。

## 字幕

- 灰色实时行是 provisional，会随句尾校正替换；
- 最终行包含英文原句和中文译文；
- 术语校正会显示校正次数，悬停可看替换详情；
- 被过滤的噪声/非英语片段默认隐藏，可在设置中显示。

## 历史

- 结束后的会话自动落盘；
- 「历史会话」可查看、重命名、删除；
- 支持导出双语 SRT、Markdown；
- 刷新页面不会删除历史。

## 讲义阅读器

1. 点「讲义」；
2. 点「打开文件」选择文件，或拖入右栏；
3. 支持 PDF、DOC、DOCX、XLSX、CSV、MD、PPTX；
4. 最近文件会保留；可重载、删除、在新标签打开 PDF；
5. 关闭右栏再打开，会恢复上次文件。

### 格式说明

- PDF 使用 Chromium 内置阅读器；
- DOCX 保留标题/段落/表格；
- DOC 在 macOS 使用 textutil；Windows 优先 Word/LibreOffice/antiword，失败时用内置 word-extractor 提取正文；
- XLSX 最多 2000 行、80 列；
- CSV 表头固定；
- MD 支持常用语法；
- PPTX 为文字 + 图片近似阅读，不保证版式。

## 刷新与历史的关系

- 同传进行中，刷新按钮禁用；
- 停止完成、会话进入 completed 后，按钮变为「保存并刷新」；
- 点击后写入 transcript、清空当前页面、刷新历史列表；
- 如果保存失败，页面保持原状，不会丢数据。
