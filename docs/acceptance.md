## 重启后怎么验

1. 看 ~/.dsh/interpret/startup.log 是否新增 loaded pid=... 与 client=true。
2. 左侧栏出现「同传」；打开后确认 ASR 状态为「就绪」。
3. 点「试翻译」验证路由。
4. 开始同传，读一段英文，观察 EN/ZH 与统计。
5. 播放一段英文视频（系统声音），确认「系统音频」字幕出现。
6. 说一句中文，确认被过滤。
7. 停止后导出双语 SRT。
